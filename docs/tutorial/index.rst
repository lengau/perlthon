Tutorial
========

This tutorial introduces you to Perlthon by walking through the main features of the
library. You will learn how to evaluate Perl code, load modules, and call functions —
all from Python.

By the end of this tutorial, you will be able to use Perlthon to access any installed
Perl module from your Python programs.


Prerequisites
-------------

Before starting, make sure you have:

- Python 3.12 or later
- Perlthon installed (``pip install .`` from the repository root)
- Perl installed on your system (usually the default on Linux)
